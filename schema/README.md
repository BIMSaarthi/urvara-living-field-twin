# Schema (stub)

This folder will hold the agri metadata schema for 3D Tiles 1.1 and the lineage-in-tile convention.

Planned contents (Milestone M1):

- `agri-schema.json`: 3D Tiles 1.1 metadata schema (`EXT_structural_metadata`) for parcels, seasons, indicators, uncertainty and honesty flags
- `lineage-convention.md`: how PROV-O lineage is carried in feature metadata via a dictionary-encoded derivation table
- `scenario-branches.md`: how what-if scenarios are stored as labelled branches beside the observed season
- `examples/`: small sample tilesets built from open data
